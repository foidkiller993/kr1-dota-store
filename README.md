# Dota 2 Store
Многостраничный сайт магазина предметов Dota 2.

## Технологии
- HTML5 (семантическая верстка)
- CSS3 (Flexbox, CSS Grid, переменные)
- JavaScript (базовый)

## Структура
- `index.html` - Главная страница
- `catalog.html` - Каталог с таблицей и формой
- `contacts.html` - Контакты
